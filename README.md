# Gen Studio Clone — Next.js

A high-fidelity implementation of the public Gen Studio Framer landing page structure using Next.js, React, CSS and Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Notes

- The implementation recreates the layout system, typography treatment, section hierarchy, hover effects, responsive breakpoints, scroll reveals and navigation behavior.
- The demo currently references image URLs hosted by the original site's Framer CDN so the visual reference is immediate. Replace these with assets you have permission to use before deploying publicly.
- Original proprietary copy, brand identity, imagery, logos and template assets may be protected by their respective owners. This code is intended as an implementation/reference starting point, not a redistribution of the original Framer template.
- The original Gen Studio template is sold/licensed through Framer Marketplace. See the source site and marketplace listing before using original assets commercially.
